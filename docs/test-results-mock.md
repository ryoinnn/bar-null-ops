## 追加で確認した動き
- 要確認（【要確認】）の文案: 赤帯・見出し・確認項目の一覧・メンション。誤ってスタンプを押しても送信せず、🚫 と理由を返す
- 追加のメッセージが来たら、未送信の文案をまとめ直す（承認済みの返信は重ねて答えない）
- 否認の指示（「否認して」）は自動では実行せず、管理画面での操作を依頼して保留
- SM の予約前の問い合わせ（【問い合わせ】の親メッセージ）
- IB のゲストからの予約変更リクエスト（文案＋管理画面での承諾・拒否の案内）
- 退室時に「気になる点があります」→ 確認 → スタンプで★5投稿
- 停止中のスタンプ・返信の拾い直し（起動時・10分ごと）
- 停止検知（プロセスが止まって30分後に「停止している可能性」）

## テスト中に見つけて直した不具合
- Slack トークンの入力で Ctrl+V が文字として保存される → 伏せ字の入力ウィンドウに変更
- 修正文をコードブロック（```）で書くと記号ごと送ってしまう → Slack の書式を外してから送信
- 判定が曖昧な返信を無視していた → 「この文面で送ってよいか」を確認
- 【要確認】の文案が通常の文案と同じ見た目 → 赤帯・見出し・一覧・メンション
- 親メッセージの要確認の件数に、承認済みの返信を数えていた → 分けて表示
- 利用完了の通知の時刻が崩れる（テスト投入の問題） → 修正
