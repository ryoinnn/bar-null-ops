## 3. スレッド画面

### サイドバー（`[class*="MainContentsWithSidebarInbox__SidebarWrapper"]`）
テキストから取得できる項目:
- 現在のステータス（時間貸し / 予約完了・利用完了・期限切れ 等）と説明文
  - 期限切れ（リクエスト）:「有効期限が過ぎたため、予約リクエストは無効になりました。」
  - 期限切れ（問い合わせ）:「有効期限が過ぎたため、お問い合わせは終了しました。」
  - リクエスト中は「期限：あと…」「※承認して予約完了になります。」が出る（画面文言データより）
- ゲスト電話番号（予約完了後のみ。**保存しない**）
- レビュー欄（利用完了後）:「期限：あと14日（2026年10月23日まで）」＋「レビューの投稿」ボタン
- 予約詳細: 日時、スペース名、**あなたの収益**（例 ¥23,100 = 合計 ¥33,000 の 70%）、振込予定日、支払方法、料金明細（プラン・消費税・合計）
- ゲスト詳細: 氏名、「ホストレビューあり」表示（レビュー投稿済みの判定に使える）、予約ID

→ **店舗収益は「あなたの収益」を使う。** 手数料率のフォールバックは 30%（合計×0.7）。

### メッセージ本文（`[class*="DetailPage__PageContents"]` 内、各ブロックは `[class*="MessagesForm__Section"]`）

| 種類 | セレクタ |
|---|---|
| ホストのテキスト | `[class*="MessageSelf__Wrapper"]` |
| ゲストのテキスト（予約リクエストの [利用目的] 等も含む） | `[class*="MessageOpponent__Wrapper"]` |
| ホストのファイル送信 | `[class*="SendFileSelf__Wrapper"]`（中の `a` が S3 署名付き URL、テキストがファイル名） |
| システムメッセージ | `[class*="Status__Content"]`（例: 予約ステータスが「保留中」/「承認」/「予約完了」になりました） |
| 退室時状態 | 本文に「ゲストが退室時の状態を記録しました／状態／問題なく退室しました／写真」 |

- 各メッセージに時刻と「既読」表示。日付見出し（「10月4日」「昨日」「今日」）。
- 予約リクエストの本文: `[利用目的] …` `[利用形態] …` `[人数] …` `[プラン] …`、利用用途の詳細があれば併記。
- 既存運用での定型文送信は、テキスト → PDF の順（予約 6248079）と PDF → テキストの順（予約 6271768）の両方あり。

### 入力欄（`[class*="FloatBottomInbox__Container"]`）
| 要素 | セレクタ |
|---|---|
| テキスト入力 | `textarea[placeholder="メッセージを入力"]` |
| ファイル添付 | `input[type=file][class*="FloatBottomInbox__InputUpload"]`（`accept="image/*,application/pdf"`） |
| 送信（PC） | `[class*="FloatBottomInbox__ContainerPc"] a`（テキスト「送信」） |

- テキストとファイルは**別メッセージ**。ファイルは選択後に確認モーダル「ファイルの送信／送信するファイルに間違いはありませんか？」が出る（画面文言データより。モーダルのボタン文言・セレクタは本番立ち会い時に確定）。

## 4. 承認（画面文言データから。実物は未確認）
- ボタン文言: 「承認」「否認」
- 確認モーダル: タイトル「予約リクエストの承認」、本文「予約リクエストを承認します。確定する場合は承認ボタンを押してください。」→ モーダル内の「承認」で確定
- 承認後の注意文:「承認後、ゲストにメッセージでスペースの利用方法や注意事項を伝えてください。」
- 承認後、システムメッセージ「予約ステータスが「承認」になりました」→ 支払い完了で「予約完了」（クレジットカードは同時刻に遷移していた）
- **未確認**: 承認ボタンの DOM。次の予約リクエスト到着時に読み取りで確定する（Phase 4 前に必須）

## 5. レビュー（`/inbox/<予約ID>/review`、`[class*="WriteReviewPage__Section"]`）
| 要素 | セレクタ |
|---|---|
| ★（5個） | `a[class*="ReputationStar__Star-"]`（5番目をクリックで★5） |
| コメント | `[class*="WriteReviewPage"] textarea`（10〜400字、placeholder「このたびはご利用ありがとうございました。…」） |
| 投稿 | 本文側の `a` テキスト「レビューの投稿」（隣に「キャンセル」「メッセージにもどる」） |

- 期限は利用完了から14日。双方投稿または期限経過で公開。公開までは編集可。
- 投稿済み判定: ゲスト詳細の「ホストレビューあり」表示（要確認）。
