# 伝票メッセージの送り方（スタッフ向け）

会計が終わったら、いつもどおり LINE グループ「Bar null」に伝票の写真を送り、続けて **`@null` で始まる伝票メッセージ** を送ってください。
売上の記録（Slack・Asana）と、Square の決済・銀行入金の確認は自動で行われます。

## 伝票メッセージ
`@` を打つと出てくる候補から「null」を選び、そのあとに内容を書きます。

```
@null
日付：10/10
顧客名：山田様
金額：100,000
プロモーターフラグ：
備考：40,000未収（10/17振込予定）
```

- 日付は営業日（朝6時までの会計は前日の営業分）。年は書かなくてよい
- 金額は伝票の総額（未収があっても総額を書き、未収は備考に書く）
- 備考が無ければ「備考：なし」
- プロモーター経由のお客様なら「プロモーターフラグ：」にプロモーターの名前（LINE の名前）を書く。違えば空のまま、または行ごと省いてよい
- 1通に複数のお客様を書いてもよい（お客様ごとに「日付・顧客名・金額・備考」を繰り返す）
- 自由な書き方でも読み取れますが、この形のほうが確実です
- 写真は今までどおり送ってください（確認用です。システムは写真を読みません）

**`@null` を付け忘れると記録されません。** 付け忘れても、あとから `@null` 付きで送り直せば大丈夫です。
読み取れなかった伝票・勤怠を、別の人が元のメッセージを **引用して** `@null` で送り直したときは、元のメッセージを送った人が担当になります。

## 間違えたとき（訂正）
送った本人が、24時間以内に送ってください。
```
@null さっきの山田様、95,000でした
```

## 未収を回収したとき
```
@null 山田様の未収4万、振込ありました
```
現金で受け取った場合は「現金で受け取りました」と書いてください。

## 現金をまとめて入金したとき
```
@null 10/3と10/5の現金分、まとめて入金しました。顧客D様と顧客A様の分です
```

## Bot が受け付けると「OK」スタンプが返ります
`@null` のメッセージを Bot が読み取れると、そのメッセージを引用した「OK」スタンプ（ブラウン）が返ってきます。
スタンプが返ってこないときは、読み取れなかったか、`@null` が付いていません。書き方を見直して送り直してください。
受け付けた内容や確認の結果は、Slack の `#daily_barnull-sales` に出ます。

## 勤怠（出勤・退勤）の送り方
勤務が終わったら、同じ LINE グループ「Bar null」に **`@null` で始まる勤怠メッセージ** を1通送ってください。
勤務時間は Slack と Asana に記録され、給与の計算に使われます。

```
@null
日付：11/23
勤務開始：21:00
勤務終了：3:00
```

- 日付は営業日（21:00〜翌朝9:00 を1日とし、始まった日の日付）。朝3時に終わった勤務も、前の日の日付で書く
- 時刻は 24時間制。0時〜9時の時刻は翌朝として読みます（「27:00」と書いても同じ）
- 休憩は書かなくてよい
- 正しく読み取れると「OK」スタンプが返ります。返ってこないときは書き方を見直して送り直してください
- **入力の期限は、営業日の2日後の朝9時まで**（例: 11/23 の勤務 → 11/25 の朝9時まで）。過ぎてから送ると「承認待ち」と返信が来ます。
  管理者が承認すると、LINE で「承認され、記録しました」と知らせます。承認されなかったものは記録されません
- 間違えたときは、同じ日付でもう一度送れば、後から送ったもので上書きされます（期限内なら承認は不要）
- 給与は月末締め・翌月25日払い。翌月の10日に確定するので、それ以降は LINE からは直せません（管理者に連絡してください）
