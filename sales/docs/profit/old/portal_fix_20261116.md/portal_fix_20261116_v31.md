# ポータルの作り直し（2026-11-16）

対象は Artifact「Bar null ポータル」（`sales/report/portal/`）。担当は #null_dev_portal-fix。本人の依頼は次の3つ。
- 画面の構成を GCP・AWS と同じにする（上部バー＋左のサイドナビ。大きな画面の切り替えはサイドナビに統一）
- 見た目を frosted ガラスから AWS Console に寄せる（本人が示した AWS Console の画面に合わせて、角丸・フォント・構造を直す）
- ホームを、売上とコストの数字から作る経営のダッシュボードにする。各ウィジェットから青字のリンクで各画面へ飛べるようにする

途中で、ホームの大きな2つのボタン（売上管理・コスト管理）は不要になった。切り替えはサイドバーだけにした（本人）。

公開: **Version 27**（2026-11-16）。同じ日に、本人の2回目の指定（フォント・黒＋緑＋オレンジの色・期間の一覧の月の囲い）を **Version 29** で公開（Version 28 は D の備品・消耗品の修正。その上に重ねた）。公開の直前に、公開中の版が Version 26（2026-11-15）のままで、ほかの会話の公開が無いことを確かめた。capabilities は変えていない。

## 直したもの

### 1. 画面の構成（index.html）
- 上部バー: ロゴと本番／テストの切り替え。テストの間は黄色の印を出す。
- 左のサイドナビ: ダッシュボード → 売上管理／コスト管理。コスト管理を開くと 全体・固定費・変動費、変動費を開くと 人件費・仕入・備品消耗品 が出る。選択中はオレンジの太字。
- パンくず（ホーム › コスト管理 › 変動費 › 仕入）。
- 各ページの期間の一覧（`.side`）は、広い画面（901px 以上）では殻がサイドナビの「期間」に移す。狭い画面ではページの上に戻す。ページの HTML は変えていない。
- スマホ: サイドナビは左上のボタンから開く引き出し。閉じているときはキーボードのフォーカスが入らない。
- 閲覧だけの人には、コスト管理をサイドナビにもパンくずにも出さない。`#cost-*` を開いたらホームに戻し、URL も `#home` にそろえる。

### 2. 見た目（shared.css）
- クラス名は前と同じにして、トークンと部品だけを置き換えた。各ページの HTML はほぼ変えていない。
- 角を立てたコンテナ（角丸なし）と、ごく薄い影。ボタン・入力は 2px の角。
- 色は「黒＋緑＋オレンジ」（2026-11-16 の2回目の指定。青は使わない）。主のボタンはオレンジ、通常のボタンは灰色の縁、リンクと大きな数字は緑。お知らせは 情報＝灰・エラー＝赤・注意＝黄。期間の一覧は月ごとに囲い、週は中の白い面にまとめる。
- フォントは英数字が Roboto、日本語は BIZ UDPゴシック（どちらも Google Fonts。2026-11-16 の3回目の指定）。
- 地の色: ライトは明るい灰色の地に白いコンテナ、ダークは紺の地。
- 費目の色（`--c-labor`・`--c-purchase` など）は shared.css に1つだけ置き、ホーム・コスト管理・売上管理でそろえた。
- 売上管理の設定にあったガラスの調整（透明度・レンズ）は隠した。sales.html のレンズの処理は動かさない。

### 3. 月ごとの集計を共通部品に（common.js `BN.ledger`）
- コスト管理（cost.html）の中にあった読み込みと月の集計を `BN.ledger` に移した。コスト管理とホームは同じ計算を使う。規則は変えていない（A が確認済み）。
- レンタルの月次確定値が無い月は、利益を断定しない（契約 §5 に合わせた）。費用がそろっていれば参考値を出す。費用が欠けた月は参考値も出さない。
- テストを2件足した（`tests/js/common.test.mjs`。全 24 件）。

### 4. ホーム（pages/home.html）＝ダッシュボード
AWS Console Home のように、見出し・本文・下端のリンクを持つウィジェットを並べた。
- **売上とコスト**: 左に大きな数字（売上合計・コスト合計・利益・原価率・人件費率）。どれも青字のリンクで各画面へ飛ぶ。右に12か月の売上とコストのグラフ。月を押すとその月を表示する。下の数字は利益で、灰色は参考値。
- **損益（滝グラフ）**: 売上合計から費目を順に引いて、残りが利益。費目の名前は青字のリンク。今月は「ここまでの損益」と呼ぶ。売上管理と同じ日割りの固定費の参考値も添える。
- **損益分岐までの距離**: 損益分岐売上 ＝ 固定費 ÷（1 − 変動費率）。あといくらか、残りの日に1日あたりいくら必要か。破線は昨日までのペースで見込んだ月末の売上。返済・配当を除いた損益分岐も並べる。
- **曜日ごとの平均売上**: 直近12週（昨日まで）、通常営業、伝票のあった日の平均。
- **データの状態**: 伝票・レンタル・給与・仕入・備品・固定費が、いつまで入っているか。名前は青字のリンク。
- 今月の計算（前月比・月末の見込み・曜日の平均）は、まだ終わっていない今日を数えない。
- 閲覧だけの人には、売上の数字・12か月の売上・曜日の平均・伝票とレンタルの状態だけを出す。費用は読まない。

## 追記: 3回目の指定（2026-11-16。Version 30 で公開）
- フォント: 日本語を BIZ UDPゴシックにした（英数字は Roboto）。
- 12か月のグラフ: 1か月の幅を 84px にして棒を太く（売上・コストとも約 28px）。幅が足りないときは横スクロール（縦の目盛りは左に固定、最初は最新の月が見える位置）。滝グラフ・曜日の棒も太くした。
- ポップアップ: グラフに触れると詳細が出る。マウスは載せると出て、押すと留まる。指は押すと留まる（触れただけでは開かない）。キーボードは Enter で留め、× にフォーカスが移る。中の数値は各画面（売上管理・コスト管理・固定費・変動費・人件費・仕入・備品消耗品）へのリンク。今月は途中の値なので、前月は「1か月分」だけを出し、差は出さない。
- 構成比の円グラフ: 管理者には「コストの内訳」、閲覧だけの人には「売上の内訳」。扇に触れると金額・構成比・前月。一覧の名前と金額は各画面へのリンク。
- レビュー（サブエージェント）: 高 0・中 4・低 4。すべて直した（今月の前月との差、指で触れただけで開く、キーボードのフォーカス、描き直しでのずれ、円の中央の合計、幅を変えたときの描き直し）。
- 残したもの: リンクは各画面を開くだけで、その画面の期間（月）までは合わせない（各ページの期間の選び方を URL で渡す仕組みが無いため）。
