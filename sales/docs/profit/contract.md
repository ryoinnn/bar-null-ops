# データの約束（A・B・C をつなぐ）

状態: **案**（2026-11-14）。B・C は自分の節を、実装して確定したら最終版に書き換える。変えるときは、先にここを直す。

## 1. 共通の原則
- 記録の置き場は **Asana の専用プロジェクト**（本番とテストの2つずつ）。レポートは、開いた人のコネクタ（`get_tasks`）で、売上の伝票と同じ方法で読む。
  Firestore は worker 側の正本・作業用で、レポートからは読めない。Firestore を失っても Asana から復元できるよう、集計に必要な事実はすべて Asana のフィールドに持つ。
- 1タスク ＝ 1記録。記録 ID を持ち、同じ入力から二重に作らない（冪等）。
- 日付の項目は、3つとも **「営業日」（日付）** という名前にする（6:00〜翌6:00 で数えた日。レポートの既存の読み取りに合わせる）。
- 取り消した・無効にした記録は、状態を「対象外」にする（削除しない）。レポートは「対象外」を数えない。
- 店舗を区別できるよう「店舗」（テキスト。既定は空 ＝ Bar null、福岡は `node`）の項目を持たせる。
- 金額は円の整数、時間は小数の時間（h）。税の扱いは §4。
- 名前（担当者）は、売上の「担当（LINE）」と同じ値（LINE の表示名）にする。照合では空白を除いて比べる。
- レポートに渡す前に、顧客名・従業員名は AI に出さない（レポートが記号に置き換える）。

**ある月 M の固定費の計算（Python `fixed.month_amounts` とレポートは同じ結果にする）**
1. 「有効」で、店舗が空で、適用開始月 ≤ M ≤ 適用終了月（空なら上限なし）のタスクを集める。
2. 項目（タスク名）ごとに、「実績」があれば実績だけを使う。無ければ「通常」のうち **適用開始月がいちばん新しいもの1つ** を使う（値上げは、新しい適用開始月のタスクを足すだけでよい）。
3. 項目の月額 ＝ 金額 ÷ 按分月数（円未満切り捨て）。ただし、適用開始月から数えて按分月数ごとの区切りの最後の月に、端数（金額 − 切り捨て額 × 按分月数）を足す。
4. M の固定費 ＝ 項目の月額の合計。項目が1つも無い月は「未設定」（0円ではない）。
- 日・週: 日の固定費 ＝ その月の固定費 ÷ その月の日数。週・任意の期間は日の値を足す（月をまたぐ週は月ごとの値で足す）。月全体は月の固定費そのもの。
- 「返済・配当」（出資者配当金・銀行借入の返済）は、経営ダッシュボードどおり固定費に含める。会計上の費用ではないので、画面では区分ごとの小計を出し、含まない額も分かるようにする（A への依頼）。
- 税込（経営ダッシュボードの金額をそのまま税込として扱う）。

| 売上（レンタル） | 店舗収益 ＝ プラットフォーム手数料を引いた振込額（ゲスト支払ではない）。売上のセクションではゲスト支払も併記 |
| 変動費 | 仕入 ＋ 人件費 ＋ 備品・消耗品（§3b。2026-11-15 追加）＋ Square の決済手数料（伝票の「決済手数料」） |
| 固定費 | Asana「Bar null 固定費」の月額（§3c。2026-11-15 から。旧: 本人が db に入力）。週・日の表示では日割りで按分 |
| 利益 | 売上 − 変動費 − 固定費 |
| 原価率 | 仕入 ÷ 売上（通常営業） |
| 人件費率 | 人件費 ÷ 売上 |
| 損益分岐売上 | 固定費 ÷ (1 − 変動費率) |

- 計上の基準は、仕入は営業日（仕入日）、人件費は営業日（勤務日）、固定費は日割り。棚卸（在庫の増減）は反映しない（注意点としてレポートに書く）。
- 金額は **税込** で統一する案（仕入・固定費・売上とも）。仕入は酒屋の請求書の税込額を使う。
- 利益は **発生ベース**（売上に未収を含む）と **入金ベース**（未収の残高を除く）の2本を出す（2026-11-14 本人回答）。
- 人件費は、勤怠に記録された額だけを数える（交通費・社会保険・深夜割増は別に足さない）。勤怠を打刻するのはアルバイトだけで、管理者（桝本）は打刻しないので含まれない。
- レンタルの対応にかかる人件費は、配分せず、人件費の合計に含める。人件費率は「人件費 ÷ 売上合計（通常営業＋レンタル収益）」、原価率は「仕入 ÷ 通常営業の売上」。
- 固定費は Asana「Bar null 固定費」から §3c の規則で計算する（2026-11-15 から。旧: Artifact の db `fixedcosts/barnull` に本人が入力。A が読み先を切り替えたら、db の入力欄は使わない）。項目が無い月は利益を出さない。
