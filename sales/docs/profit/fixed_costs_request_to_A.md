# A への依頼: 固定費の読み先を Asana「Bar null 固定費」に切り替える（E より。2026-11-15）

データの約束は [contract.md](contract.md) §3c。計算の正解は Python の `sales/src/barnull_sales/fixed.py`（`month_amounts`・`period_total`）と `tests/test_fixed.py`。

## 1. 読み先
- プロジェクト: `sales/asana_ids.json` の `fixed.{test|prod}.project`（本番 `1220539995299165`、テスト `1220539920443902`。2026-11-15 作成・写し済み）。
  `COST_PROJECTS` に `fixed: { prod: "1220539995299165", test: "1220539920443902" }` のように足す。
- 読む欄: タスク名（項目）、固定費区分、金額（税込）、按分月数、適用開始月、適用終了月、固定費種別、固定費ステータス、店舗。
- `pages/cost.html` の `fixedOf(m)` と、`pages/sales.html` の `fixedVersion`・`fixedStats` を、§3c の計算に置き換える:
  1. 有効・店舗が空・適用開始月 ≤ M ≤ 適用終了月（空は上限なし）を集める。
  2. 項目ごとに、実績があれば実績、無ければ通常のうち適用開始月がいちばん新しいもの。
  3. 月額 ＝ floor(金額 ÷ 按分月数)。適用開始月から数えて按分月数ごとの区切りの最後の月に端数を足す。
  4. 項目が無い月は「未設定」（0円ではない）。日 ＝ 月 ÷ その月の日数。
- db `fixedcosts/barnull` の入力欄（設定の中）は外す。編集は Asana で行う、と案内する。

## 2. 固定費の画面（`#cost-fixed`）に足すもの
- KPI: 損益分岐売上と実際の売上の差（％）、前月差。今ある「月額・売上に対する割合・1日あたり」はそのまま。
- 区分別の小計（家賃・共益費／光熱・設備／契約・サービス／返済・配当／その他）。項目の横棒は区分で色をまとめる。
- 「返済・配当を除いた固定費」を1行（出資者配当金・銀行借入の返済は会計上の費用ではないため、参考として）。
- 項目の一覧に、按分（年払い等）・適用期間・「実績」の印。
- 推移: 区分別の積み上げ（直近6か月）と、売上に対する比率。
- 今後3か月で金額が変わる・終わる項目（適用開始月が先の月のタスク、適用終了月が近いタスク）。
- 利益・示唆に渡す固定費の項目名は、そのまま渡してよい（個人名を含まない）。
