# 固定費管理 要件定義書（セッション E）

状態: **確定**（2026-11-15）。データの約束は [contract.md](contract.md) §3c、運用は `docs/runbook.md`「固定費」。
本人回答（2026-11-15）: 確認事項は「推奨でOK」。項目と金額は「Asana『Bar null 経営ダッシュボード』の月ごとの固定費をそのまま流用」。

## 1. 目的
毎月かかる固定費を、項目・金額・適用期間つきで漏れなく保持し、変更履歴を残し、
売上レポートのコスト管理「固定費」（`#cost-fixed`）と利益の計算に渡す。

## 2. 決定事項
| 項目 | 決定 |
|---|---|
| 項目と金額の元 | 経営ダッシュボード（`1213897227136198`、岡本さん管理）の「大分類 ＝ 固定費」のタスク（年月・金額）。`fixed-import` で金額の変わり目ごとにまとめて写す。経営ダッシュボードには書かない |
| 項目（2026-11 時点） | 家賃、共益費、ゴミ回収費、通信費、カラオケ費、リース費、ガス代、設備利用費（セコム・水道・電気）、出資者配当金、銀行借入の返済、その他（金額は Asana にだけ置く） |
| 正本 | Asana の非公開プロジェクト「Bar null 固定費」（本番・テスト）。1タスク ＝ 1項目 × 1適用期間 |
| 編集者 | 管理者2人が Asana で編集。画面は読むだけ。A の db 入力欄（`fixedcosts/barnull`）は読み先の切り替え後に使わない |
| 変更履歴 | 金額が変わるときは新しい適用開始月のタスクを足す（古いタスクは残る）。Asana のタスク履歴も残る |
| 税 | 税込（経営ダッシュボードの値をそのまま） |
| 日割り | 月の固定費 ÷ その月の日数。月全体は月の固定費そのもの |
| 年払い・半年払い・減価償却 | 「按分月数」で毎月に割る（端数は区切りの最後の月） |
| 光熱費など変わる項目 | 通常の額を置いておき、請求額は「実績」のタスク（その月だけ）で置き換える |
| 返済・配当 | 経営ダッシュボードどおり固定費に含める。会計上の費用ではないので、画面で区分の小計を分けて見せる |
| 店舗 | 「店舗」欄（空 ＝ Bar null）。福岡 Node は当面含めない |
| 定期実行 | 足さない（写しは手元で必要なときだけ実行） |

## 4. 画面の要件（A への依頼。[fixed_costs_request_to_A.md](fixed_costs_request_to_A.md)）
- 読み先を db から Asana「Bar null 固定費」に切り替え、§3c の規則で月・日の固定費を計算する。
- KPI: 固定費（月額）、売上に対する割合、1日あたり、損益分岐売上（固定費 ÷（1 − 変動費率））と実際の売上の差、前月差。
- 内訳: 区分別（家賃・共益費／光熱・設備／契約・サービス／返済・配当／その他）の小計と、項目の一覧（金額・按分・適用期間・実績の別）。
- 「返済・配当を除いた固定費」も1行で出す。
- 月次推移: 直近6か月の区分別の積み上げ。売上に対する比率の折れ線。
- 今後3か月で金額が変わる・終わる項目（適用開始月・終了月から）。
- 未設定のとき: 「固定費が未設定です。Asana『Bar null 固定費』に入力します」。
