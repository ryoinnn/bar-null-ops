# 伝票メッセージの送り方（スタッフ向け）

会計が終わったら、いつもどおり LINE グループ「Bar null」に伝票の写真を送り、続けて **`@null` で始まる伝票メッセージ** を送ってください。
売上の記録（Slack・Asana）と、Square の決済・銀行入金の確認は自動で行われます。

## 伝票メッセージ
`@` を打つと出てくる候補から「null」を選び、そのあとに内容を書きます。

```
@null
日付：10/10
顧客名：山田様
金額：100,000
備考：40,000未収（10/17振込予定）
```

- 日付は営業日（朝6時までの会計は前日の営業分）。年は書かなくてよい
- 金額は伝票の総額（未収があっても総額を書き、未収は備考に書く）
- 備考が無ければ「備考：なし」
- 1通に複数のお客様を書いてもよい（お客様ごとに「日付・顧客名・金額・備考」を繰り返す）
- 自由な書き方でも読み取れますが、この形のほうが確実です
- 写真は今までどおり送ってください（確認用です。システムは写真を読みません）

**`@null` を付け忘れると記録されません。** 付け忘れても、あとから `@null` 付きで送り直せば大丈夫です。

## 間違えたとき（訂正）
送った本人が、24時間以内に送ってください。
```
@null さっきの山田様、95,000でした
```

## 未収を回収したとき
```
@null 山田様の未収4万、振込ありました
```
現金で受け取った場合は「現金で受け取りました」と書いてください。

## 現金をまとめて入金したとき
```
@null 10/3と10/5の現金分、まとめて入金しました。顧客D様と顧客A様の分です
```

## Bot が受け付けると「OK」スタンプが返ります
`@null` のメッセージを Bot が読み取れると、そのメッセージを引用した「OK」スタンプ（ブラウン）が返ってきます。
スタンプが返ってこないときは、読み取れなかったか、`@null` が付いていません。書き方を見直して送り直してください。
受け付けた内容や確認の結果は、Slack の `#daily_barnull-sales` に出ます。
