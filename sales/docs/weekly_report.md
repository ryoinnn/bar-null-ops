# 売上週報

Asana は伝票データの蓄積場所（台帳）として使い、レポートは1つの Artifact で見る（2026-10-17 本人の方針）。

## 売上レポート（Artifact）
- URL: https://claude.ai/artifact/8BynYgvNxC4UyCQVGRUDnC
- 原本: `sales/report/weekly_report.html`（変更したら Claude が同じファイルから公開し直す。URL は変わらない）
- 見た目: Apple 風のすりガラス（フロストガラス）の UI。アクセントは赤ピンク。ライト・ダークの両方に対応（2026-10-24 本人の希望）
- サイドバー: 年 → 月の囲み → 週。月の囲みの見出しを押すとその月全体、年の見出しを押すとその年全体の集計になる
  - 週は月曜〜日曜。月をまたぐ週は月で区切る（月の最初と最後の週は日数が少ないことがある。日数を併記）
  - 進行中の期間は「集計中」。狭い画面では「期間を選ぶ」で開く。下に「ガラスの透明度」の調整がある
- 紙面の内容（選んだ期間ごと）
  - 売上・予約数・客単価・1日あたり（前の期間比。進行中の月・年は前の期間の同じ日数まで、日数の違う週は1日あたりで比べる）
  - 日ごとの売上（年は月ごと）、推移（週: 直近12週、月: 直近12か月、年: 年ごと）、曜日ごとの平均
  - 内訳（伝票のあった日、売上の最も高い日、リピートのお客様、決済手数料、未収、状態ごとの件数）と伝票の一覧（年では出さない）
- AI の示唆: 「示唆を作成」を押すと、Claude が傾向・今後の見通し・進むべきアプローチをまとめる
  - 渡すのは集計した数字だけ（直近8週の日ごと、16週、12か月、曜日平均、リピート率、上位顧客の集中度、手数料率、未収）。顧客名・伝票 ID は渡さない
  - 押した人の Claude の利用枠を使う（最初の1回は許可を求められる）。結果は Artifact のデータベース（`insights/<本番|テスト>_<期間>`）に残し、次に開いた人は利用枠を使わずに読める
  - 作成後に伝票が増えたり訂正されたりすると「作成後にデータが更新されています」と出る。「最新のデータで作り直す」で作り直す
- レンタルスペース（2026-10-25 追加）: 通常営業とは別の欄で集計する
  - 予約通知（Slack #notif_space-rent_null）から、利用日ごとの件数・ゲスト支払・店舗収益・利用時間・用途・初回の割合・これからの予約（速報）
  - Asana の月次確定値（伝票ID が RS- で始まるタスク。予約対応システムが毎月1日に前月分をプラットフォームごとに記録）
  - 通常営業の売上・Slack の週報には、RS- のタスクを数えない
  - AI の示唆は「総評」「通常営業」「レンタルスペース」の3欄。Claude に渡すのは集計値と、予約1件ごとの利用日・時間帯・金額・人数・用途の分類だけ（名前・本文は渡さない）
- データ: 開いた人の Asana コネクタ（claude.ai で接続した Asana）で、本番用プロジェクトのタスクをその場で読む（1分キャッシュ）
  - 開く人は claude.ai で Asana（0x0.co.jp のアカウント）を接続し、ページの許可を1回出す必要がある
  - サイドバー下の切り替えで、テスト用プロジェクトのデータも見られる
- 確定値の記録: 終わった週（月曜〜日曜）の売上・予約数・客単価を Artifact のデータベース（`weeks/prod_<週の月曜>`）に記録する（集計値だけ。顧客名は入れない）。Asana を読めないときに表示する
- 共有: 初めは本人だけが開ける。ほかの人に見せるときは、ページの「共有」から招待する

## Slack の週報（毎週月曜 9:10）
Cloud Scheduler `sales-weekly` → sales-worker `/jobs/weekly`。`#weekly_barnull-sales` に短く通知する。

```
*売上週報 10/12〜10/18*
先週（10/12〜10/18）の売上：¥120,000
今月（10/1〜10/18）の売上：¥260,000
詳細レポート：https://claude.ai/artifact/8BynYgvNxC4UyCQVGRUDnC
```

## 定義
| 指標 | 定義 |
|---|---|
| 売上 | 伝票金額の合計（未収分を含む。伝票ステータスが「対象外」（取消）の伝票は除く） |
| 予約数 | 伝票の件数（1伝票＝1組） |
| 客単価 | 売上 ÷ 予約数（1組あたり。人数は記録していない） |
| 今月の売上 | その週の日曜（今週なら今日）が属する月の1日から、その日まで |
| 前月同期 | 前月の同じ日付の範囲（前月に無い日付は月末まで） |
| 期間 | すべて営業日（6:00〜翌6:00）で数える。週は月曜〜日曜 |

## 手で出す・試す
```powershell
cd sales
uv run barnull-sales report --env prod --date 2026-10-19      # Slack の文面を画面に表示するだけ
gcloud.cmd scheduler jobs run sales-weekly --location=us-central1 --project=barnull-sales   # 本番の Slack に今すぐ出す
```

## Asana のダッシュボード
本番用プロジェクトの「ダッシュボード」タブには、伝票ステータス別の伝票金額と、未収ステータス別の未収残高のグラフがある（2026-10-17 作成）。
日付を軸にしたグラフは Asana の Advanced プランが必要なため作っていない。推移は上の売上レポートで見る。
